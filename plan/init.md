# MineCraft Typing

ช่วยผมออกแบบ game หน่อย ผมอยากทำ material ให้ครบถ้วน รวมทั้ง screenshort ให้เรียบร้อย ก่อนส่งให้ AI ช่วยเขียน code ให้ โดยเริ่มจากเขียนให้ AI เข้าใจก่อนว่าผมอยากได้อะไร

เป้าหมาย ทำเกมส์ฝึกพิมพ์ดีดสัมผัส เน้นความคล่องในการกดแป้มพิมพ์

## รูปแบบของเกมส์

เหมือนเกมส์ Minecraft ทั้งวัตถุ ตัวละคร สภาพแวดล้อม Animation และ Interaction แต่มุมมองและการควบคุมจะเปลี่ยนไป ดังนี้

แม้ว่าจะเป็นเกมส์สามมิติ แต่มุมมองของเกมส์จะมองจากด้านข้าง คล้ายๆ เกมส์ Contra ตัวละครของเราจะยืนอยู่ทางขวาสุด หมุนไปหมุนมา ทำท่าทางน่ารัก

O <- ตัวละครเอก
Z <- Zombie

ตัว Zombie แต่ละตัวจะมีตัวอักษรอยู่ข้างบนหัว ผู้เล่นต้องพิมพ์ตัวอักษรให้ถูกต้อง Zombie ถึงจะตาย ถ้าพิมพ์ถูกหนึ่งตัว Zombie ก็จะทำท่าเหมือนโดนตีหนึ่งครั้ง (ไม่สนใจว่าจะห่างไปไกลแค่ไหน) ถ้าพิมพ์ครบตัวอักษร ก็จะตาย (Animation, Interaction เหมือน Minecraft)

ถ้าผู้เล่นพิมพ์หนึ่งครั้ง ก็จะดูว่ามี Zombie ตัวไหนที่ขึ้นต้นด้วยตัวอักษรนั้นบ้าง ก็จะโดนตีหมด (แล้วตัวอักษรตัวแรกก็จะเปลี่ยนจากสีขาวเป็นสีแดง) ถ้า Zombie ตัวไหนมีอักษรแค่ตัวเดียวก็จะตายเลย

พอพิมพ์ครั้งที่สอง ก็จะดูว่ามี Zombie ตัวไหนที่โดนชุดแรกไปแล้วบ้าง แล้วในกลุ่มนั้นมีใครโดนตัวไหนที่มีตัวอักษรของการพิมพ์ครั้งที่สองบ้าง ตัวไหนตรงก็จะโดนดี (แล้วตัวอักษรตัวที่สองก็จะเปลี่ยนจากสีขาวเป็นสีแดง) ส่วน Zombie ที่ไม่เข้ากลุ่ม ตัวอักษรก็จะกลายเป็นสีขาวหมด ถ้า Zombie ตัวไหนที่ตัวอักษรเป็นสีแดงหมดแล้วก็จะตายเลย

ถ้ายังไม่มีตัวไหนตาย ก็พิมพ์ครั้งที่ สาม สี ห้า ไปเรื่อยๆ จนกว่าจะมีการตาย

เมื่อตายแล้วทุกตัวที่เหลือก็จะมีตัวอักษรกลับเป็นสีขาวหมด

Zombie จะเดินจากทางขวามาทางซ้าย ผู้เล่นต้องฆ่า Zombie ให้หมดด้วยการพิมพ์ให้ถูกต้อง เพื่อป้องกันไม่ให้ Zombie มาถึงตัว ถ้ามาถึงตัวเกมส์ก็จะจบ

## Screen

หน้าแรกผู้เล่นจะเลือก Play, Setting

หน้า Play ผู้เล่นจะเลือกว่าตัวเองจะเล่นที่ Level ไหน

เมื่อกดเลือกก็จะเข้า Level นั้นๆ

## Storage

ให้เก็บข้อมูลบน Browser ไปก่อน

ผมจะเชื่อมระบบเข้ากับ Firebase แล้วถ้าผู้เล่น Login ก็จะเก็บข้อมูลบน FireStore

(การเชื่อมต่อ Firebase จะเอาไว้ทำ Phase 2 แต่ก็ให้ออกแบบการเก็บข้อมูลให้เอาขึ้น FireSore ได้ง่ายๆ )

## การแบ่ง Level

1. Zombie: จะมี level ย่อยๆ เริ่มไปทีละ 2 ตัวอักษร เริ่มจากตัวอักษรที่อยู่บนแป้นเย่า

2. Skeliton: จะมี level ย่อยๆ เริ่มที่ละ 2 ตัวอักษรเช่นกัน แต่จะพยายามฝึกให้กดที่ key ของแป้นเย่า และ key ที่ฝึก เช่น Level ของ R U ก็จะมีตัวอักษร F R J U เพื่อให้จำได้ว่าต้องใช้นิ้วอะไร

3. Creeper: จัด Level ย่อยๆ เป็นคำสั้นๆ ไม่เกิน 7 ตัวอักษร และเป็นคำที่ใช้บ่อยๆ ไล่จากคำง่ายๆ ไปหาคำที่ยากขึ้น

4. Dragon: เริ่มมาเป็นประโยค แต่ไม่ยาวมาก

## Phase การพัฒนา

1. ทำ prototype ของแต่ละหน้าออกมาก่อน ยังไม่ต้องมี interaction ใดๆ เริ่มจากหน้า game play, select level, home
2. ทำ Interaction หน้า game play ดูว่า Zombie เดินยังไง พิมพ์แล้ว Zombie ตายจริง ตามแผนที่วางไว้
3. ทำ interaction ของ flow Home -> select leve -> Gameplay

แต่ละ phase จะมีการปรับแก้มากมายหลังจากจบ phase 3 ค่อยมาดูว่าจะทำอะไรต่อ
